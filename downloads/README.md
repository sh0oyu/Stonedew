# Download Stonedew

[**Download stonedew-0.2.5-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.5-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping only one Stonedew version.

P1 includes planting, watering, fueled lamps and growth to ripe plants. Version 0.2.5 rebuilds the foliage/flowers and every current equipment model, adds ray-baked vertex ambient occlusion and richer UV effects, and includes the full pot/tent/lamp reference art catalog. Use `/stonedew debug art` in a disposable Creative world with clear space to inspect the labeled previews. Future-tier models are art displays; automation and harvesting remain deferred. See [installation](../README.md) and [actual captures/lighting limits](../docs/art/ART_DIRECTION.md).

Each binary has an adjacent SHA-256. Older binaries remain archived; install only one Stonedew JAR.
