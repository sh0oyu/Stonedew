# Download Stonedew

[**Download stonedew-0.2.8-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.8-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping only one Stonedew version.

P1 includes planting, watering, fueled lamps and growth to ripe plants. Version 0.2.8 revises the rejected sparse 0.2.7 plant: shorter branches, overlapping foliage through the center, individually bent leaf fingers and a quieter painted leaflet source. Smaller flowers keep the established volume, adding raised bracts; foliage shadows are softer. Saved identities and 5/9/13 flower loads remain. See actual game captures in the main README.

Use `/stonedew debug art` in a disposable Creative world with clear space to inspect the labeled catalog. Future-tier models are art displays; automation and harvesting remain deferred. See [installation](../README.md) and [actual captures/rendering limits](../docs/art/ART_DIRECTION.md).
