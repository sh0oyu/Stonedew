# Download Stonedew

[**Download stonedew-0.2.1-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.1-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping only one Stonedew version.

P1 adds planting, watering, fueled lighting and growth to ripe plants, revised organic plants with puffy buds and curved leaves, HUD and Ledger. Harvest/processing remain P3. See [installation](../README.md) and [playtest](../docs/P1_PLAYTEST.md).

Each binary has an adjacent SHA-256. The older P0 binary is archived for history; it contains only the original foundation.

0.2.1 corrects the plant art direction. Older binaries remain archived; do not install them together.
