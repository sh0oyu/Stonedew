# Download Stonedew

[**Download stonedew-0.2.4-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.4-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping only one Stonedew version.

P1 includes planting, watering, fueled lamps and growth to ripe plants. Version 0.2.4 rebuilds the leaf/flower presentation, replaces the active texture sheet with authored pixel art, fixes missing face/underside shading, and adds canopy occlusion, contact shadows and local UV light spill. Saved branch/size variation and 5/9/13 visible mature flower sites remain. Harvest/processing remain P3. See [installation](../README.md) and [current captures](../docs/art/ART_DIRECTION.md).

Each binary has an adjacent SHA-256. Older binaries remain archived; install only one Stonedew JAR.
