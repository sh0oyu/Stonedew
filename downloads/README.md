# Download Stonedew

[**Download stonedew-0.2.3-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.3-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping only one Stonedew version.

P1 includes planting, watering, fueled lamps and growth to ripe plants. Version 0.2.3 rebuilds all current equipment and foliage against CODEX_REFERENCE_NEW, with persistent branch/size variation and 5/9/13 visible mature flower clusters. Harvest/processing remain P3. See [installation](../README.md) and [playtest](../docs/P1_PLAYTEST.md).

Each binary has an adjacent SHA-256. Older binaries remain archived; install only one Stonedew JAR.
