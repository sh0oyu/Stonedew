# Download Stonedew

[**Download stonedew-0.2.9-p1.jar**](https://github.com/sh0oyu/Stonedew/raw/refs/heads/main/downloads/stonedew-0.2.9-p1.jar)

Requires **Minecraft Java 1.21.1 / NeoForge 21.1.264**. Put the JAR in that installation's `mods` folder without extracting it. **Remove older Stonedew JARs**, keeping one version.

0.2.9 rebuilds the five-finger foliage, plant proportions, smaller flowers, shared equipment materials and field-journal UI. It fixes the large plant rendering cost and adds **four placeable tents, three plantable pots and three fueled lamps**, available in the Stonedew tab and Survival crafting. Tents use the current manual care loop; climate simulation, processing and automation remain in later phases.

See [installation, actual game captures and usage](../README.md), [performance measurements](../docs/performance/0.2.9.md) and the adjacent SHA-256. Older binaries remain archived.
